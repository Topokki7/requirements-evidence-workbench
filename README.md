# 需求证据与方案变更跟踪工作台

一个面向项目需求、验证任务、证据和方案版本管理的本地交互原型。当前案例以外卖盒防漏汤需求为演示背景，所有业务数据均为合成数据。

## 功能

- 以需求为中心查看关联验证任务
- 管理需求、任务和方案版本的新增与修改
- 跟踪测试结果、证据、审核、验收与重新测试流程
- 模拟需求、方案、验收标准或证据变化的影响
- 保存本机演示状态，并支持一键恢复

## 本地运行

项目为纯静态网页。可使用任意静态文件服务器打开 `dist` 目录，例如：

```bash
npx serve dist
```

然后访问终端显示的本地地址。

## 说明

- 不接入真人账号、外部通知或真实项目数据。
- 浏览器中的编辑内容保存在本机 `localStorage`。
- 演示结果不代表真实产品通过测试或获得认证。
